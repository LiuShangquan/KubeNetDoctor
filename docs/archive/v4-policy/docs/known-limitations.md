# 已知边界与待验证事项

状态：所有功能仍处于设计阶段。本文件说明拟交付范围，不是已有实现的测试结论。

## 1. 功能范围

- 一个 Linux/IPv4 集群、单主网络、每节点单 PodCIDR；首个平台 Linux amd64。其他架构、IPv6、多网卡、多集群不在当前交付范围。
- CNI 处理普通 Pod 的基本网络；策略仅作用于固定实验 Namespace 的端点。非受管 Pod 不挂本项目策略程序，系统网络不接受该策略模块保护。
- 仅验证普通 PodIP 直连 TCP 的入站策略子集。Egress、ipBlock、matchExpressions、命名端口、endPort 及非 TCP 策略端口等明确不支持。
- UDP/SCTP 等非分片 IPv4 流量显式旁路；ICMP/ARP 保留规定的基础行为。因此“TCP 隔离”不能写成“全部网络隔离”。IPv4 分片及受管端点的 IPv6/VLAN/未知二层类型按处理表拒绝。
- ClusterIP、NodePort、Service NAT、出网、hostNetwork、外部来源、Service Mesh 不作策略兼容性承诺。本机节点到本机 Pod 的例外单独验证；“任意来源”测试不能代替全部外部流量语义。
- 不与另一个主 CNI 混装。使用隔离实验集群；不将部署本项目当作改造现有业务集群的授权。

完整支持/拒绝表以 [数据面设计](datapath-and-policy.md) 为准。

## 2. 状态与一致性

- 有限 TCP 状态只证明已观察握手下的授权关系，没有完整 TCP 窗口、拥塞、重传及 conntrack 语义；不支持 TFO/SYN 数据、simultaneous open。
- 已存在同 tuple 的不同 ISN 新连接可能等待关闭/清理；授权具有硬期限，持续长连接也可能需要重连。具体候选时间见数据面文档，不是内核 TCP 默认行为。
- 正常规则收紧不立即撤销已批准连接。端点删除/异常隔离优先失效，但正在执行旧快照的报文可能完成；不承诺零在途包窗口。
- 本节点附件 epoch 隔离本地重建。远端身份依赖 API 的 IP/UID 更新，存在传播延迟；同一 Pod UID 下 sandbox 重建没有天然的跨节点附件 epoch 通知。本版不保证远端即时识别这种代际变化。
- 来源 IP 与 PeerToken 的关联依赖可信实验节点/underlay及受管端点的本地防伪造校验，不是报文携带的加密身份。非受管 Pod 不挂本项目程序，须作为可信实验来源；本版不保证阻止其伪造地址，也不防御恶意宿主机或全部二层攻击。
- map-in-map 只给出节点内快照引用替换；binding、隔离标记、流状态与路由不是跨 Map/netlink 原子事务。节点之间独立收敛。
- API 中断时使用最后已提交配置；Agent 重启不代表策略同步仍持续。节点内核重启、ABI 不兼容升级可能需要重建网络/连接，不声称无损升级。
- BPF timer 与 spinlock 的组合、资源占用和回收竞态尚未验证，是进入完整连接状态实现前的门禁。

## 3. 拓扑与性能

- Native 直接路由需要可达下一跳、双向回程及允许 Pod 源地址的 underlay。云上同一子网并非充分条件。
- VXLAN 复用 Linux 封装；自研部分是设备、路由、邻居、FDB 的控制。不能描述为自行实现完整 VXLAN 协议或 eBPF 转发栈。
- R2 是两种固定模式的独立验证；在线切换、自动 native/VXLAN 混合选路、BGP、ECMP 优化均后置。JD 的混合拓扑要求只能部分覆盖。
- VM 独立内核不等于独立物理资源；kind 节点共享内核。测试报告必须记录这一差别与 CPU/网卡干扰。
- 没有 GPU/RDMA/DPDK 或真实千节点环境，不将编译器压力测试当成大规模生产经验。
- 容量、内存预算、更新时间与工作日都是候选规划值；不提供未经实验支持的吞吐提升、延迟下降或完成日期。

## 4. M0 与各阶段需要落定的事项

| 阶段 | 待确认 | 对后续的影响 |
|---|---|---|
| M0 | 可用 Linux 环境、内核/BTF/helper、工具链和权限 | 确定 TC/Map/锁/timer 实现是否可用 |
| M0 | 实际地址、网卡/MTU、独立内核资源、runtime 参数 | 固定拓扑及可信 Pod UID 契约；不根据名称补猜 UID |
| M2 | C/Go ABI、非线性 skb/offload 行为、异常包动作 | 确定解析器与 Map 的实际兼容范围 |
| M3 | 编译容量、真实内存、更新延迟 | 冻结适用规模与性能验收门槛 |
| M4 | 握手、tuple 复用、回收/初始化竞态和关闭状态 | 通过前仅声明实验 ACL，不声明返回流策略正确 |
| M5 | CNI 引导、PodIP 回写、节点探测、真实策略语义 | 决定 R1 的实际支持矩阵 |
| M6–M7 | VXLAN/offload/MTU 与性能瓶颈 | 决定保留何种优化及可公开的结论 |

实施时逐项把“候选”改为有版本、命令和结果的记录；环境变化后重新核查相关结论。无代码和实验结果的部分持续标为未实现。
